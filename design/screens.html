R3.11 · implemented · targeted checks passed

Tools tab — runtime capabilities

The Tools tab groups the scanner hero with Core tools, File conversion, Other tools, and AI tools. Office conversion routes use the configured HTTPS service. Summary reflects Apple Intelligence readiness; Translation checks language availability, and assisted extraction presents editable candidates for review. Scanner, PDF, local conversion, ZIP, and bounded unencrypted 7-Zip/RAR routes remain available. The expanded iOS unit suite passes 361 tests; Office passes 51 HTTP checks; physical-device checks and HTTPS service deployment remain.

R4 · implemented
